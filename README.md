# 🌈 RP2350 Multi-Board Rainbow Firmware

Продвинутая прошивка на языке C для микроконтроллеров серии **Raspberry Pi RP2350** (включая **Pico 2** и платы от **Waveshare**), реализующая плавную анимацию спектра («радуга») на адресуемом RGB-светодиоде WS2812B (NeoPixel) с применением аппаратно-управляемого автомата состояний **PIO (Programmable I/O)**.

Проект включает готовый пайплайн **GitHub Actions** для автоматической компиляции `.uf2` файлов под разные физические платы и публикации их в разделы **Releases**.

## ⚡ Как это работает

### 1. Аппаратный протокол WS2812B через PIO (`ws2812.pio`)

Светодиоды WS2812B требуют строгого соблюдения микросекундных таймингов при передаче данных (однопроводный интерфейс):

* **Бит `0**`: Высокий уровень `T1` (~0.35 мкс), затем низкий уровень `T2 + T3` (~0.9 мкс).
* **Бит `1**`: Высокий уровень `T1 + T2` (~0.7 мкс), затем низкий уровень `T3` (~0.6 мкс).

Вместо загрузки процессорного ядра постоянными задержками и прерываниями, программа загружается в сопроцессор **PIO0**:

* Данные передаются из C-кода в FIFO-буфер сокета PIO.
* PIO сдвигает биты из регистра `TX FIFO` со скоростью **800 кГц** и напрямую управляет линиями GPIO без участия CPU.

### 2. Алгоритм смены цвета (`main.c`)

* **Цветовой круг**: Функция `get_rainbow_color()` вычисляет плавный перекат между значениями Red $\to$ Green $\to$ Blue $\to$ Red по 256 дискретным позициям.
* **Ограничение яркости**: Для предотвращения чрезмерного энергопотребления, нагрева и ослепления применяется масштабирующий коэффициент `0.2f` (20% от максимальной яркости).
* **Формат цвета**: Данные упаковываются в 24-битный формат **GRB** (Green-Red-Blue), который является стандартным для контроллеров WS2812.

### 3. Автоматическая сборка в GitHub Actions (`build.yml`)

При создании нового запуска воркфлоу через вкладку **Actions**:

1. Разворачивается контейнер `ubuntu-latest` с тулчейном `gcc-arm-none-eabi`.
2. Подтягивается актуальный репозиторий `raspberrypi/pico-sdk` со всеми субмодулями.
3. Используется **Matrix Strategy** для параллельной компиляции прошивки сразу под несколько плат:
* `pico2` (Стандартная Raspberry Pi Pico 2)
* `waveshare_rp2350_zero` (Компактная плата Waveshare RP2350-Zero)


4. Собранные бинарные файлы `.uf2` маркируются и упаковываются в раздел **GitHub Releases** с выбранным тегом (например, `v1.0.0`).

## 🛠 Локальная сборка и компиляция

### Требования

* **CMake** версии 3.13 или выше
* **GCC ARM Toolchain** (`arm-none-eabi-gcc`)
* Установленный **Pico SDK** и переменная окружения `PICO_SDK_PATH`

### Инструкция по сборке

1. Клонируйте репозиторий с субмодулями:
```bash
git clone --recursive [https://github.com/qkryt/templated.git](https://github.com/qkryt/templated.git)
cd templated

```


2. Укажите путь к SDK (если он не настроен глобально):
```bash
export PICO_SDK_PATH=/path/to/pico-sdk

```


3. Создайте директорию сборки и скомпилируйте проект:
```bash
mkdir build
cd build
cmake -DPICO_BOARD=pico2 -DPICO_PLATFORM=rp2350 ..
make -j$(nproc)

```



Для сборки под плату **Waveshare RP2350 Zero** замените значение ключа `PICO_BOARD`:

```bash
cmake -DPICO_BOARD=waveshare_rp2350_zero -DPICO_PLATFORM=rp2350 ..
make -j$(nproc)

```

В результате в папке `build/` появится готовый файл `rainbow.uf2`.

## 🔌 Прошивка устройства

1. Зажмите и удерживайте кнопку **BOOTSEL** на плате RP2350.
2. Подключите плату к компьютеру через USB-кабель и отпустите кнопку.
3. Плата смонтируется как съемный накопитель (например, `RPI-RP2`).
4. Перетащите скомпилированный файл `rainbow.uf2` на накопитель.
5. Микроконтроллер автоматически перезагрузится и запустит радужную анимацию!

## ⚙️ Настройка пина светодиода

По умолчанию пин светодиода задается автоматически из конфигурационных файлов используемой платы (`PICO_DEFAULT_WS2812_PIN`).

Если вы используете собственную разводку, пин можно переопределить в файле `main.c`:

```c
#ifndef PICO_DEFAULT_WS2812_PIN
#define PICO_DEFAULT_WS2812_PIN 16 // Укажите номер вашего GPIO
#endif

```
